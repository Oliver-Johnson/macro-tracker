# Code of conduct

This is a small project about tracking food, so this is short.

## What is expected

Be decent to people. Assume the person you are replying to is trying to help and may
know things you do not. Criticise the design or the code — not the person who made it.

Beginners are welcome and questions are not a nuisance.

## What is not

Harassment, insults, or personal attacks. Sexualised language or imagery. Publishing
anyone's private information. Sustained disruption of a discussion. Discrimination or
demeaning comments on the basis of who someone is — including age, disability,
ethnicity, sex characteristics, gender identity or expression, nationality, appearance,
race, religion, or sexual orientation.

## Scope

This applies anywhere the project is being represented: issues, pull requests, commits,
and any space where someone is speaking as part of this project.

## Reporting

If someone is behaving this way, report it privately rather than arguing in the thread:

- [Open a private report](https://github.com/Oliver-Johnson/macro-tracker/security/advisories/new)
  on this repository, or
- use [GitHub's report abuse form](https://github.com/contact/report-abuse) if the
  behaviour is better handled by GitHub directly.

Reports are handled privately, and the reporter is not named in any resulting action.

Consequences are proportionate and at the maintainer's discretion: usually a note
asking someone to stop, and where that does not work, removal of comments or a block.

---

If you would rather this project used the standard
[Contributor Covenant](https://www.contributor-covenant.org/) instead, that is a
reasonable request — open an issue and say so.
