Changelog

A history of every update to Macrolog.

v2026-10-07.3 7 October 2026 Latest
New
  • Desktop Log Food — on a computer, Log Food opens on Search (listed first) with the cursor in the search box, and your frequent foods sit in a panel beside the results. Scan puts the camera beside the label tools, Manual and Quick lay their fields out in two columns with boxed inputs, and Describe shows the estimate beside your description. Tablets still open on Scan
  • Desktop Settings — two columns: daily targets (four to a row on wide screens), saved foods and the developer cards on the left; help, appearance (toggles in two columns) and data (buttons in a grid) on the right
  • Desktop Fasting — the status and last 7 days on the left, the protocol on the right
  • Recipes — pressing Enter adds the ingredient (Add to Recipe on the weight step, Add on the manual form). On a computer the search box, weight and name fields are focused for you
Changed
  • Fasting — the disabled message now says to turn the tracker on in Protocol, since Protocol is beside it on desktop
v2026-10-07.2 7 October 2026
New
  • Desktop layout — on screens 1024px and wider the nav moves to a sidebar and Today splits into two columns, with the rings, meals and food log on the left and water, exercise, notes, averages and weight on the right. Trends and Macro History charts get more room, and sheets open as centred dialogs. Tablets get the phone layout, centred. Phones are unchanged
v2026-10-07.1 7 October 2026
Fixed
  • Targets wizard — when it is offered as the app opens (for someone who finished or skipped the tour earlier the same day without setting targets), it now opens instead of stopping the rest of the app from loading
v2026-10-06.3 6 October 2026
Fixed
  • Targets wizard — new users are offered it once, after the tour or after skipping it. It never opened before, because default targets were saved on launch before the app checked for them, so new users started on 2,500 kcal
v2026-10-06.2 6 October 2026
Fixed
  • Chart dates — the dates under the Trends and Macro History charts were cut off and now show in full
  • Trends axis labels — the kg and kcal labels no longer overlap the top axis values, and the first and last bars no longer cover the axis numbers
  • First-run tour — steps whose target isn't on screen now show the tip in the middle instead of pointing at the top corner
  • Ko-fi card — on tablets and larger screens it sits above the bottom navigation instead of behind it
  • History calendar — the "Jump to Today" button was hidden behind the bottom navigation, so tapping it opened Settings instead
  • Additional Nutrients — the section in Manual and Quick Add now collapses when you tap its heading; it stays open by default
  • Food names — names in the macro breakdown popup are now shown as plain text, so a product name containing HTML can't change the page
  • Docs What's New — the update cards now appear in Chrome; they stayed hidden because the reveal never triggered
v2026-10-06.1 6 October 2026
Fixed
  • Custom foods — new installs no longer start with a set of pre-filled custom foods, and foods you delete from your list no longer reappear the next time the app opens
v2026-09-02.2 7 September 2026
Fixed
  • Scan result Log button — the barcode scan result popup now clears the bottom nav bar, so the Log button is always fully visible and tappable
Docs 7 September 2026
Docs
  • Feature guides — new pages for recipes, installing, appearance, trends, the barcode scanner, nutrition label scanning and custom foods
  • Developer & AI guide — sync server setup, remote access options and AI features in one place
v2026-09-03.8 (beta) 3 September 2026
New
  • Recipe drafts — save a recipe as a draft before it's finished, and delete drafts you no longer need
Fixed
  • Status bar colour — follows the selected style and is never purple
  • Bold nav — the floating nav hides behind open popups, the setup wizard and the on-screen keyboard
  • Gradient style — glass styling now covers every page, with a stronger gradient in light mode
  • Water buttons — use the selected style's colours
v2026-09-02.1 2 September 2026
Docs
  • Docs redesign — premium scroll-driven landing page with chapter layout, macro ring animation, and dedicated AI Features section
v2026-09-02.1 (beta) 2 September 2026
New
  • Beta channel — separate beta PWA at beta.macroslog.co.uk with all 7 UI themes
  • 7 visual styles — Current (default), Bold (neon-green, giant kcal, floating pill nav), Gradient (purple-to-teal glassmorphism), Zen (minimal, ring hidden, lightweight number), Soft (warm cream/terracotta, pill-everything), Editorial (clinical blue, sharp 4px corners), Retro (terminal green-on-black / amber-on-cream)
  • Style selector in Settings → Appearance; persists in localStorage; orthogonal to dark/light/auto colour mode
v2026-08-31.1 31 August 2026
Improvements
  • Configurable sugar limit — new Sugar limit (g/day) field in Settings; warning threshold is automatically set to 75% of the configured limit; default remains 60g
v2026-08-29 29 August 2026
New features
  • ✨ Describe tab in Log Food — type a meal description and get AI-estimated macros (name, weight, kcal, protein, carbs, fat, fibre) with a confidence badge and assumptions note; review and edit before adding to log
  • AI Daily Summary card on the Today page — button-triggered personalised review with wins, improvements, and tomorrow's focus; result cached per day to avoid re-billing
  • AI Weekly Review on the Trends page — analyses the full week's logs and returns patterns, recommendations, and a next-week focus
  • AI settings card in Settings → Developer Mode: enable toggle, provider select (Claude / Gemini / OpenAI), API key field, optional model override; key stored on-device only
  • Sync server moved to sync-server/ in the repository with a README
v2026-08-29 29 August 2026
New features
  • Bearer-token authentication for the self-hosted sync server — set SYNC_API_KEY on the server and requests without a matching token are rejected with 401
  • API key field in Settings → Sync Server; the key is sent as an Authorization: Bearer header on every sync request
  • New Sync API documentation section — endpoints, request/response format, auth and 2-command reference-server setup
Improvements
  • Sync failures caused by a wrong API key now show a clear “Sync failed — wrong API key” message
  • Reference sync server hardened — request bodies over 5 MB rejected and POST payloads validated as JSON with expected keys
v2026-08-29 29 August 2026
New features
  • Dark / Light / Auto theme toggle in Settings → Appearance
  • TDEE wizard — biological sex selector (male/female) for accurate BMR calculation
  • TDEE wizard — new diet style step: Standard, High Protein, Carb Heavy, Low Carb, Keto with live macro preview
  • Onboarding tour now navigates to the relevant page for each step (Today, Log Food, Recipes, Trends, Fasting)
  • Tour — three new Log Food steps: search, barcode scanner (explains auto-save to Saved Foods), Saved Foods list
  • Tour — final step prompts PWA install (native button on Android/Chrome, Share instructions on iOS, unsupported-browser message otherwise)
  • Settings — "Take the tour again" button
  • Changelog page at macroslog.co.uk/docs/changelog.html
  • Docs — "What's New" section and "Supported Browsers" table with install support matrix
Bug fixes
  • Fixed startup crash (TDZ) silently breaking the Trends chart and corrupting data exports for all users
  • Fixed Ko-fi X button not dismissing on mobile
  • Fixed data export generating dailyTargets: null; import now validates all fields before writing
  • Tour retake no longer injects demo data over existing user data
  • Tour finish no longer deletes real food/weight/water logs when no demo data was injected
  • Tour data backed up and auto-restored on startup if an abandoned tour session is detected
  • Removed personal historical macro targets that were being injected into every new user's history
Improvements
  • Default macro targets changed to standard reference values (2500 kcal for male audience)
  • Ko-fi support card is session-only — reappears each time the app is opened
  • Settings reordered: Docs & FAQ → Take Tour → Appearance → Data → Support Me → Developer Mode
  • "Admin Mode" renamed to "Developer Mode"
  • PWA install prompt is browser/platform-aware — recommends Chrome/Opera/Samsung on mobile, Chrome/Edge on desktop
  • README updated to point to macroslog.co.uk; self-hosting instructions removed
  • GitHub Actions CI workflow added

v2026-08 (early) August 2026
Foundation
  • Initial release as a Progressive Web App (PWA)
  • Food logging with barcode scanning (Open Food Facts database)
  • Manual food entry with full macro breakdown
  • Recipe builder — combine ingredients and save as a meal
  • TDEE wizard — calculate your targets from height, weight, age, and activity level
  • Trends page — calorie and weight charts over 2 weeks, 1 month, or 3 months
  • Offline-first with service worker caching
  • Data export and import (JSON)
