04 — Developer Features

Self-host, sync, and extend.

Power-user tools for running your own infrastructure and integrating AI on your own terms.

Sync Server

Self-hosted

Your data, your server

The sync server is a lightweight Flask app that lives in the sync-server/ subfolder of the repo. Run it anywhere — a Raspberry Pi, a VPS, or a spare laptop. All food log data stays on infrastructure you control.

Auth

Bearer token authentication

Set a SYNC_API_KEY environment variable on the server. The app sends this key as a Bearer token on every sync request. No accounts, no OAuth — just a secret you control.

HTTPS

Cloudflare Quick Tunnel

Expose your local server over HTTPS in one command with a Cloudflare quick tunnel. No port-forwarding or cert management required. Suitable for personal use; see the repo README for named-tunnel setup if you want a stable URL.

Setup

How to connect

  1. Clone the repo and start the Flask server: SYNC_API_KEY=secret flask run
  2. Run cloudflared tunnel --url localhost:5001 to get a public HTTPS URL
  3. In the app, open Settings → Developer Settings
  4. Paste the tunnel URL and your API key into the Sync Server fields
  5. Tap Sync now — your food log will upload immediately

Full setup guide and Docker instructions: github.com/Oliver-Johnson/macro-tracker

AI Features

Describe tab

AI meal description

Open the Describe tab in Log Food and type what you ate in plain language: "chicken tikka masala with rice, restaurant portion". The AI returns a name, estimated weight, calories, protein, carbohydrates, fat, and fibre, along with a confidence indicator and the assumptions it made. Review and edit the values before adding to your log.

Today page

AI Daily Summary

Tap the summary button on the Today page for a personalised review of the day: what went well, where you drifted from targets, and one concrete focus for tomorrow. Cached per day so it does not re-run on every tap.

Trends page

AI Weekly Review

On the Trends page, the weekly review analyses all seven days of logs and returns patterns across macros, consistency scores, and a specific focus for the coming week. Useful for adjusting targets that are consistently over or under.

Setup

How to enable AI

  1. Open Settings and enable Developer Mode
  2. Find the AI card and toggle it on
  3. Pick a provider: Claude, Gemini, or OpenAI
  4. Paste your API key (stored on-device only, never sent to Macrolog servers)
  5. Optionally override the model name for your chosen provider
03 — How to Use

Up and running in minutes.

Five steps from install to your first logged meal.

  1. 1

    Install as a PWA

    Open macroslog.co.uk in Safari or Chrome. Tap "Add to Home Screen" (iOS) or "Install app" (Android/Chrome) to install it as a native-feeling app, no app store required.

  2. 2

    Set your targets in Settings

    Enter your daily calorie goal, protein, carbohydrate, fat, and sugar limits. Macrolog stores them locally on your device.

  3. 3

    Log meals manually or with AI Describe

    Type a food item and its macros, or tap "AI Describe" and write a plain-language description: "chicken breast, rice, broccoli, about 400g". The AI estimates the split and adds the entry.

  4. 4

    Check the Today ring for progress

    The macro ring updates as you log. Tap any segment to see the breakdown. A warning indicator appears if you approach your sugar limit.

  5. 5

    Review Trends weekly

    Open the Trends tab on any day to see your last 7 or 30 days at a glance. Use the AI weekly summary to get a plain-language read on your consistency.
