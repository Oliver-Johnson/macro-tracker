Features

📷

Barcode Scanning

Point your camera at any product barcode. Nutrition data is pulled automatically from Open Food Facts.

🔍

Food Search

Search millions of products by name using the Open Food Facts database — no API key required.

✎

Manual Entry

Add custom foods to your personal database with full macro data. Great for home cooking and staples.

🍳

Recipe Builder

Compose recipes from individual ingredients. Log by total weight or serving portion.

📈

Daily Dashboard

Progress rings and bars show calories, protein, carbs, fat and fibre versus your targets at a glance.

🕑

History View

Browse any past day's food log. Useful for reviewing patterns and seeing what worked.

⚡

Offline-First

All data is stored locally. Barcode lookups are cached after first scan. Works without internet.

📥

Data Export

Export your entire food log as JSON at any time. Your data is yours.

How to use it

1

Open the app

Visit macrolog.co.uk in Safari (iOS) or Chrome (Android). Camera access requires HTTPS — macrolog.co.uk serves over HTTPS automatically.

2

Install to your home screen

On iOS: tap the Share button, then "Add to Home Screen". On Android: tap the browser menu and select "Install app". It will launch in full-screen standalone mode like a native app.

3

Set your targets

Go to the Settings tab and enter your daily calorie and macro targets. These are stored locally — no account needed.

4

Log meals

Tap "+" to add a food. Scan a barcode, search by name, pick from your recent foods, or enter custom macros manually. Adjust the weight and confirm.

5

Watch your progress

The dashboard updates in real time. Progress rings fill as you get closer to each target. Check back throughout the day.

Tech stack

Vanilla HTML/CSS/JS Progressive Web App (PWA) Service Worker IndexedDB / localStorage Web App Manifest Open Food Facts API Camera / MediaDevices API Cloudflare / Custom domain

Zero npm dependencies. No build step. The entire app ships as a single index.html file plus a service worker — fast to load, easy to audit.
